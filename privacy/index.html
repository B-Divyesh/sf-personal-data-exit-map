Policy sheet / P-01

Privacy

Effective 28 August 2026

Your exports stay on your device

Personal Data Exit Map processes selected ZIP, JSON, and CSV files in your browser. It does not upload archive bytes, file names, inventory results, or checksums to us. The app does not ask for account credentials or archive passwords.

What is stored locally

The app stores derived assessments in your browser’s IndexedDB: archive and file names, sizes, formats, CRC-32 values supplied by the ZIP, the archive SHA-256, category mappings, checklist state, and a locally generated signing key. Original archive contents are not stored. You can remove individual maps from the Saved maps section or clear this site’s browser data.

Network requests

After installation, the app shell can run offline. This release contains no analytics, advertising, tracking pixels, third-party fonts, runtime CDN scripts, or cloud processing. Following an official service guide link leaves this site and is governed by that service’s policy.

Exports you create

Assessment JSON, CSV inventories, and signed manifests are downloaded only when you request them. They can contain sensitive file names and account history. Store and share them as carefully as the original archive.

Contact and changes

This open-source utility is maintained through its public source repository. Material policy changes will be dated on this page.
